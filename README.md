# 売上レポート自動作成ツール（AI所見つき）

POSやECから出力した **売上CSVを読み込むだけ** で、月別・店舗別・カテゴリ別の集計とグラフを作り、
**AI（Claude）が数字を読み解いて「気づき」と「来月の打ち手」を書いた Excel レポート** を作成します。

> 「月末の売上集計に毎回半日かかる」
> 「数字は出しても、何が起きているのかまで書く時間がない」
>
> といったお悩みを想定して作成したデモです。

## できること

| シート | 内容 |
|---|---|
| サマリー | 最新月の売上合計・前月比と、AIによる見出し・気づき・打ち手 |
| 店舗別 | 店舗×月の売上表と推移グラフ |
| カテゴリ別 | カテゴリ×月の売上表とグラフ |
| 売れ筋 | 最新月の売上上位5商品 |

### 出力例（`--mock` で実行した場合の「サマリー」シート）

```
売上合計  2,530,080円
前月比    +15.8%
所見（簡易） 2026-09の売上は2,530,080円（前月比+15.8%）
気づき    ・オンラインが前月比+45.5%と最も伸びています
          ・横浜店は前月比-8.7%と最も落ち込んでいます
          ・売上1位の商品は「ギフトセットL」です
打ち手    ・横浜店の落ち込みの原因（客数・客単価）を確認する
          ・オンラインで売れている商品を他店舗でも展開する
```

AIで実行すると、「9月はギフトが伸びた一方、横浜店は2か月連続で減少」のように（イメージ）、
複数の数字を組み合わせた所見と、より具体的な打ち手を書きます。

## 使い方

```bash
# 1. 依存パッケージのインストール（uv を使用）
uv sync

# 2-a. お試し：APIキーなしで動かす（決まった型の簡易コメント）
uv run sales-report data/sample_sales.csv -o output/sales_report.xlsx --mock

# 2-b. 本番：AIが所見を書く
export ANTHROPIC_API_KEY=sk-ant-...
uv run sales-report data/sample_sales.csv -o output/sales_report.xlsx
```

入力は次の列を持つCSVです（Excelで保存したCSVもそのまま読めます）。

```
date,store,category,product,quantity,unit_price
```

## 設計上の工夫

- **集計はプログラム、解釈はAI**：金額の計算はすべてプログラムで行い、AIには集計済みの数字だけを渡します。AIに計算させないため、レポートの数字は常に正確です
- **数字を作らせない指示**：AIには「渡された数字だけを使う」「どの店舗の、いつと比べた話かを明記する」よう指示しています
- **AIが失敗してもレポートは届く**：AIの応答に失敗した場合は簡易コメントに切り替え、集計とグラフは必ず出力します（AIによる所見かどうかはシート上に表示）
- **入力チェック**：存在しない日付や負の数量などを、何行目のどの列かまで分かるエラーで知らせます
- **テスト**：pytest による自動テスト（AI部分はAPIを呼ばずに検証）

```bash
uv run pytest --cov=sales_report
```

## 構成

```
src/sales_report/
├── models.py     # 売上・集計結果・所見のデータ型
├── loader.py     # CSVの読み込みと入力チェック
├── aggregate.py  # 月別・店舗別・カテゴリ別の集計
├── insights.py   # Claude による所見 / ルールベースの簡易コメント
├── report.py     # Excelレポートの作成
└── cli.py        # コマンドラインの入口
scripts/generate_sample.py  # 架空のサンプルデータの生成
```

## カスタマイズ例

- 毎月1日に自動実行し、レポートをメール・Slack・Chatworkで送る
- Googleスプレッドシートやクラウドの売上データから直接取り込む
- 予算比・前年同月比の追加、粗利の集計
- 所見の観点（在庫・客単価・キャンペーン効果など）を業種に合わせて調整

※ サンプルデータはすべて架空のものです（`scripts/generate_sample.py` で生成）。
